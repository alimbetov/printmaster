## 15. Offline state

Compact banner:

```
Offline · Your changes are kept on this device
```

Approval/checkout remain unavailable until sync returns.

## 16. Responsive invariants

- canvas remains dominant;
- product/side context never disappears;
- Preview is always reachable;
- Design check state is visible;
- mobile never gets a compressed desktop inspector;
- approval always happens on a read-only screen;
- bottom dock never gets more than 4 primary actions.
